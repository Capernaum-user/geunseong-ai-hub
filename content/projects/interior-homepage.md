인테리어 디자인 브랜드의 웹 경험을 가정하고, 3D 연출과 인터랙션을 결합한 데모 사이트를 직접 만들어 본 프로젝트입니다.

## 배경 / 문제

인테리어처럼 "공간과 질감"을 파는 분야는 평범한 이미지 나열만으로는 감각이 잘 전달되지 않습니다. 스크롤과 마우스 움직임에 반응하는 동적 연출을 통해, 정적인 포트폴리오보다 몰입감 있는 브랜드 경험을 웹에서 어떻게 구현할 수 있을지를 실험 주제로 잡았습니다.

## 접근 · 기술 스택

- **프런트엔드** — Next.js(App Router)와 React 기반. Hero 섹션에 React Three Fiber(Three.js)로 3D 씬을 얹고, Framer Motion으로 섹션 전환과 마이크로 인터랙션을 다뤘습니다.
- **3D 연출** — 선언형 R3F로 장면을 구성해 React 컴포넌트 사고방식 그대로 카메라·조명·머티리얼을 제어했습니다. 3D 에셋 로딩 실패 시 플레이스홀더로 안전하게 대체되는 폴백 로직을 넣어 화면이 멈추지 않도록 했습니다.
- **프런트/백 분리 아키텍처** — 화면은 프런트엔드가 전담하고, 별도의 Node.js/Express + SQLite 백엔드가 상담 입력과 단계별 이벤트를 받아 저장하는 구조로 나눴습니다. API URL을 환경 변수로 주입해 로컬과 배포 환경을 동일 코드로 운용합니다.
- **데이터 관점** — 상담 폼을 단순 저장이 아니라 단계별 퍼널 이벤트로 기록하도록 설계해, 어느 단계에서 이탈이 일어나는지 분석할 수 있는 어드민 대시보드까지 붙였습니다.

## 상태 / 배운 점

초기 데모 단계로, 3D 연출이 들어간 랜딩부터 상담 마법사, 어드민 통계 화면까지 한 흐름으로 묶고 배포 검증을 마쳤습니다. 화면(프런트)과 데이터(백)를 명확히 분리하니 각 레이어를 독립적으로 다루기 쉬웠고, "보여주는 연출"과 "쌓이는 데이터"를 처음부터 같이 설계하는 것이 사용자 행동을 이해하는 데 핵심이라는 점을 체감했습니다.
