# Notedeck — 로컬-퍼스트 스티키 노트 데스크톱 앱

> 바탕화면 위에 떠 있는 플로팅 스티키 노트. 클라우드도, 외부 동기화도 없이 **내 컴퓨터 안에서만** 동작한다.

## 쉽게 말하면

> **한마디로:** Peek에서 **외부로 나가는 연결을 전부 끊고 핵심만 남긴** 로컬 전용 스티키 노트 앱입니다. 데이터가 내 컴퓨터를 절대 떠나지 않습니다.

같은 코드 뿌리에서 "무엇을 빼느냐"가 제품 성격을 바꾼다는 걸 보여주는 사례입니다.

```mermaid
flowchart LR
    P[Peek<br/>외부 연동 많음] -->|덜어내기| N[Notedeck<br/>로컬 전용]
    N --> S[SQLite 단독 저장<br/>기기 밖으로 안 나감]
```

## 배경 — 왜 만들었나

위젯 [[peek|Peek]]은 노트 동기화·메신저 전송·파일 감시 등 여러 외부 연동을 품고 있었습니다. 하지만 "그냥 화면에 메모만 붙여 두고 싶다"는 가장 단순한 쓰임에는 그 연결 고리들이 오히려 부담이었습니다. 동기화가 꼬이면 메모 자체를 못 믿게 되는 문제도 있었고요.

## 접근 — 덜어내기

Notedeck은 Peek에서 **파생**해, 외부로 나가는 모든 길을 끊고 핵심만 남긴 버전입니다.

- 저장은 로컬 SQLite 단독 — 데이터가 기기를 떠나지 않는다.
- 동기화·전송·인덱싱 모듈 전부 제거 → 코드와 동작이 단순해진다.
- 플로팅 창 · 보드(피벗) 뷰 · 리치 텍스트 편집 같은 "쓰는 경험"만 집중해서 남긴다.

스택은 Tauri 2 + Svelte 5 + Rust. 무거운 일렉트론 대신 가벼운 네이티브 코어를 택했습니다.

## 상태 / 배운 점

개인이 직접 쓰는 도구로 동작하는 단계입니다. 같은 코드베이스에서 **무엇을 빼느냐**가 제품의 성격을 바꾼다는 걸 확인한 사례로, 연결을 늘리는 방향(Peek)과 끊는 방향(Notedeck)을 한 뿌리에서 비교해 볼 수 있었습니다.
