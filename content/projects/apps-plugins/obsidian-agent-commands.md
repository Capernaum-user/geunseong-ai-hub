# Obsidian 에이전트 커맨드 허브 플러그인

여러 AI 코딩 에이전트의 슬래시 커맨드와 실행 옵션을 Obsidian 안에서 한곳에 모아 조회·조립·삽입하는 플러그인이다.

## 쉽게 말하면

> **한마디로:** 에이전트마다 제각각인 **슬래시 커맨드를 옵시디언 안에 모아**, 골라서 값을 채우면 프롬프트를 조립해 바로 끼워 넣어 주는 치트시트 겸 빌더입니다.

명령을 외우고 손으로 조립하던 마찰을 노트 옆에서 없앴습니다.

```mermaid
flowchart LR
    T[도구별 커맨드 치트시트] --> B[매개변수 입력·조립]
    B --> P[프롬프트 미리보기]
    P --> I[에디터 삽입·복사]
```

## 배경 / 문제

에이전트마다 슬래시 커맨드와 실행 플래그가 제각각이고 매개변수도 많다. 매번 문법을 외우거나 흩어진 메모를 뒤지다 보면 작업 흐름이 끊긴다. "어떤 명령이 무슨 일을 하고, 어떻게 조합하는가"를 노트 작업대 안에서 바로 꺼내 쓰고 싶었다.

## 접근 / 기술 스택

도구별 탭으로 커맨드를 격리 분류하고, 각 명령의 동작·규칙·템플릿을 사이드바 치트시트로 보여준다. 매개변수가 많은 명령은 입력 필드를 띄워 값을 토글할 때마다 실시간으로 프롬프트 문자열을 조립·미리보기하고, 활성 에디터에 즉시 삽입하거나 클립보드로 복사한다. 사용자가 자주 쓰는 프롬프트를 커스텀 명령으로 등록해 도구 탭에 연동할 수도 있다. TypeScript와 Obsidian Plugin API로 작성하고 esbuild로 빌드해 Vault 플러그인 폴더로 배포한다.

## 상태 / 배운 점

초기 단계의 개인용 데스크톱 플러그인으로 동작한다. 핵심 교훈은 에이전트 워크플로의 마찰 대부분이 "명령을 기억하고 조립하는 손작업"에 있다는 점이다. 치트시트와 빌더를 노트 옆에 두는 것만으로 컨텍스트 전환 비용이 크게 줄었다. 기획 기록과 코드 루트를 분리해 관리한 것도 유지보수에 도움이 됐다.
