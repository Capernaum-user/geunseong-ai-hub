## 쉽게 말하면

> **한마디로:** 옵시디언에서 **버튼 몇 번**으로 이 블로그의 메뉴를 고치고, 미리 보고, 인터넷에 공개하는 **리모컨**입니다. 코드는 안 만져도 됩니다.

위 그림처럼 〈카테고리 관리 → 미리보기 → 배포〉 순서로 흘러가며, 각 단계가 옵시디언 안의 버튼 하나에 대응합니다.

## 이게 왜 좋아요?

예전엔 메뉴(카테고리)를 하나 바꾸려 해도 **코드 파일을 직접 열어서 고쳐야** 했어요. 무섭고 실수하기 쉽죠.
이 플러그인을 켜면 옵시디언 안에서 **클릭만으로** 이걸 다 할 수 있어요:

- 🗂️ 메뉴(카테고리) 추가·수정·삭제
- 👁️ 올리기 전에 **미리보기**
- 🚀 버튼 한 번으로 **블로그에 공개(배포)**

---

## 1. 처음 한 번만: 켜기 (3단계)

1. 옵시디언을 열고 → **`content` 폴더를 보관소(vault)로 열기**
   *(좌측 하단 보관소 이름 클릭 → “다른 보관소 열기” → “폴더를 보관소로 열기” → `13_quartz-mywiki-site\content` 선택)*
2. **설정 → 커뮤니티 플러그인 → “제한 모드(Restricted)” 끄기**
3. 목록에서 **Quartz Hub Manager** 를 **켜기(토글 ON)**

✅ 켜지면 화면 **왼쪽 세로 막대(리본)** 에 아이콘 2개가 생겨요:
- **▦ (격자 모양)** = 카테고리 관리 열기
- **▷ (재생 모양)** = 미리보기 시작

> 💡 안 보이면? “둘러보기(Browse)”가 아니라 **“설치된 플러그인” 목록**에서 찾으세요. 그래도 없으면 옵시디언을 **재시작**.

---

## 2. 🗂️ 메뉴(카테고리) 만들고 고치기 — 가장 자주 쓰는 기능

여기서 “카테고리”는 **홈 화면의 색깔 카드**와 **맨 위 메뉴**예요 (에이전트 · 하네스 · 제품 …).

**여는 법:** 왼쪽 **▦ 아이콘** 클릭. (또는 `Ctrl+P` → “허브 관리자 열기”)

창이 열리면 이걸 할 수 있어요:

| 버튼 | 하는 일 |
|---|---|
| ➕ 추가 | 새 메뉴 만들기 |
| ✏️ 편집 | 이름·색·설명 바꾸기 |
| ↕️ 위/아래 | 메뉴 순서 바꾸기 |
| 🗑️ 삭제 | 메뉴 빼기 |

### 새 메뉴 추가 — 따라하기

1. **▦ 열기 → “추가” 클릭**
2. 빈칸을 채워요:
   - **주소 이름(영문)** — 예: `daily-log`  ← 영어 소문자와 하이픈만! 이게 인터넷 주소가 돼요.
   - **메뉴 이름(한글)** — 예: `일상 기록`
   - **짧은 이름 / 영문 이름 / 한 줄 설명** — 카드에 보일 글자
   - **색** — 색깔 칸을 누르면 색 고르는 창이 떠요 🎨
3. **저장** 누르면 → 홈 카드와 위쪽 메뉴에 **자동으로 생겨요.** 그 메뉴의 첫 글(소개 페이지)도 알아서 만들어집니다.

> 💡 **안심 포인트**
> - 메뉴를 지워도 **그 안의 글(폴더)은 안 지워져요** — 목록에서만 빠집니다.
> - 이미 있는 글은 **덮어쓰지 않아요.**
> - 칸을 잘못 채우면(예: 한글 주소, 중복 이름) **저장 전에 알려줘요.**

## 3. 👁️ 미리보기 — 올리기 전에 내 PC에서 확인

올리기 전에 “이렇게 보이는구나”를 먼저 보는 기능이에요.

1. 왼쪽 **▷ 아이콘** 클릭 (또는 “미리보기 시작”)
2. 잠깐 준비한 뒤 **브라우저에 내 사이트가 자동으로 떠요** (`localhost:8080`)
3. 글을 고치고 저장하면 → **화면이 자동으로 새로고침** 돼요
4. 다 봤으면 “미리보기 중지”

쉽게 말해 **“올리기 전 미리 보는 창”** 입니다. 여기서 보이는 건 아직 **나만** 봐요(인터넷 공개 아님).

---

## 4. 🚀 배포 — 진짜 블로그에 공개하기

확인이 끝났으면 인터넷의 진짜 내 블로그에 올리는 단계예요.

1. `Ctrl+P` → **“배포”**
2. **확인 창**이 떠요 → 무엇을 바꿨는지 간단히 적고 **확정**
3. 알아서 정리하고 업로드 → **1~2분 뒤 인터넷 블로그에 반영** 돼요

쉽게 말해 **“공개 버튼”** 이에요.

> ⚠️ **이건 인터넷에 진짜 공개돼요.** 그래서 누를 때 **한 번 더 확인**을 물어봅니다. 비공개로 두고 싶은 글은 올리지 마세요.

## 5. ⚙️ 설정 (대부분 그대로 두면 됨)

| 설정 | 뜻 | 기본값 |
|---|---|---|

| 미리보기 포트 | 미리보기 주소의 숫자 | `8080` |

평소엔 **건드릴 필요 없어요.** 자동으로 맞춰집니다.

## 6. 자주 묻는 것 (FAQ)

- **Q. 플러그인이 안 보여요.**
  → `content` 폴더를 보관소로 열었는지, **“설치된 플러그인”** 목록에서 찾는지 확인. 그래도 없으면 옵시디언 재시작.
- **Q. 핸드폰에서도 되나요?**
  → 아니요, **컴퓨터(데스크톱) 전용** 이에요.
- **Q. 색은 어디서 바꿔요?**
  → 메뉴 추가/편집 창의 **색 칸**을 누르면 색 고르는 창이 떠요.
- **Q. 실수로 배포했어요.**
  → 글을 고치고 다시 배포하면 덮어써집니다. (인터넷 캐시 때문에 몇 분 걸릴 수 있어요.)

## 그림을 더 “손그림” 느낌으로 바꾸고 싶다면

이 페이지의 그림은 SVG예요. **Excalidraw(손그림) 스타일**로 바꾸려면 Excalidraw 앱을 켜면(`localhost:3000`) 그 스타일로 다시 그려 넣을 수 있어요.
참고로 옵시디언의 `.excalidraw.md` 파일 자체는 이 블로그에 그대로 안 떠서, 그림은 **SVG/PNG로 내보내 이미지로** 넣습니다.
