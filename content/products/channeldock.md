# ChannelDock — 여러 SNS에 한 번에 발행

> 하나의 콘텐츠를 **Instagram·Facebook·LinkedIn·YouTube에 한 번에** 기획하고 예약·발행하는 SNS 발행 플랫폼.

## 어떤 문제에서 출발했나

[[company-intel/index|회사 인텔 · REUEL MASION]]을 정리하면서 반복해서 마주친 현실이 있었습니다. **"여러 광고매체에 동시에 홍보하고 싶다"**는 니즈입니다.

- 채널마다 따로 로그인해 같은 글을 복사·붙여넣기 하는 일이 매번 반복된다.
- 플랫폼마다 글자 수·이미지 규격·영상 규칙이 달라 그때그때 손이 간다.
- 어떤 캠페인이 어느 채널에 언제 나갔는지 추적이 흩어진다.

ChannelDock은 이 반복을 **한 화면에서 작성 → 채널별로 다듬기 → 예약 발행**의 흐름으로 묶어 줄이는 것을 목표로 합니다.

## 주요 기능

- **멀티 채널 작성기(Post Composer)** — 공통 본문을 한 번 쓰면 채널별 탭(Instagram·Facebook·LinkedIn·YouTube 등)으로 갈라 각 플랫폼에 맞게 다듬는다.
- **플랫폼 규칙 검증** — 글자 수 초과, 이미지 잘림 등 플랫폼 규칙 위반을 발행 전에 경고한다.
- **예약 발행** — 정한 시각에 맞춰 각 채널로 자동 발행한다(YouTube는 영상 업로드 포함).
- **워크스페이스 분리** — 브랜드·고객사 단위로 계정과 발행 큐를 분리해 섞이지 않게 한다.
- **연결 상태 관리** — 채널 연동(OAuth) 상태와 토큰 만료를 표시하고, 끊기면 재연결을 안내한다.

## 어떻게 만들었나

- **인증**: 각 플랫폼의 OAuth 2.0으로 채널을 안전하게 연결한다. 계정 비밀번호를 직접 받지 않는다.
- **백엔드**: 발행 큐·예약 워커가 정해진 시각에 각 플랫폼 API로 콘텐츠를 전송한다.
- **보안 원칙**: API 키·토큰 같은 민감 정보는 코드나 문서에 평문으로 남기지 않고 외부 환경설정으로 분리한다. (이 위키에도 자격증명은 일절 적지 않는다.)

## 지금 어디까지 왔나 (솔직한 현황)

ChannelDock은 **클로즈드 베타** 단계입니다. 과장 없이 적으면 다음과 같습니다.

- **동작하는 것** — 회원가입·로그인, 채널 연동, 멀티 채널 작성·예약·발행의 기본 흐름이 돈다. 백엔드 테스트와 풀스택 라이브 부팅을 거쳐 검증을 쌓는 중이다.
- **다듬는 중** — 출시 전 보안·안정화 점검을 진행 중이다. 일부 플랫폼의 인증 세부(예: 공급자별 OAuth 지원 차이)와 대형 화면 코드 정리는 실제 검수와 함께 단계적으로 처리한다.
- **아직 아닌 것** — 누구나 가입하는 공개 출시 단계는 아니다. 제한된 사용자와 함께 검증하며 다듬는 중이다.

"테스트가 통과했다 = 바로 출시 가능"이 아니라는 기준으로, 무리하게 공개를 서두르지 않고 결함을 먼저 해소하는 방향을 택했습니다.
